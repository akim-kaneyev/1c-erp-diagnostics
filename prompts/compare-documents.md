# Сравнение двух документов / состояний

Сравни контрольный и проблемный пример. Не объясняй общую теорию 1С, пока не построено фактическое сравнение.

Сформируй:
1. Одинаковые признаки.
2. Отличающиеся признаки.
3. Отличия в движениях по каждому доступному регистру.
4. Отличия в количестве / сумме / аналитиках / регистраторах.
5. Какие отличия могут объяснить симптом.
6. Какие отличия являются шумом.
7. Что нужно проверить для доказательства причинности.
8. Итоговый статус вывода.
