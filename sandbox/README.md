# OpenSandbox integration

OpenSandbox используется опционально как изолированная среда запуска Codex/скриптов.

## Помещаем в sandbox
- обезличенные материалы конкретного кейса;
- этот репозиторий;
- локальные инструменты `tools/`;
- Codex CLI / другой агент при необходимости.

## Не помещаем
- production `.dt`;
- секреты в открытом виде;
- необезличенные полные выгрузки;
- доступ к рабочей базе по умолчанию.

## Порядок
1. Отдельная sandbox-сессия на кейс.
2. Ограничить outbound network.
3. Передать минимум файлов.
4. Выполнить инвентаризацию и локальный анализ.
5. Запустить Codex с `AGENTS.md`.
6. Забрать результат.
7. Уничтожить sandbox.

Sandbox защищает среду выполнения, но не превращает гипотезу в доказательство.
