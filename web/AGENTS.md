# Diagnostic viewer

Follow the installed ui-sdk skill. Before using components, read node_modules/@ui-sdk/react/docs/llms.txt and the relevant component pages. Use UI SDK parts for every interactive control. Keep original case data immutable, preserve exact statuses and treat filtering, file-hash verification and accounting validation as distinct operations.

This application is local and read-only. No database bridge, network data destination or ERP action belongs in this viewer. Test actual state after human and agent actions, including rejected changes, empty results and dialog focus recovery.
