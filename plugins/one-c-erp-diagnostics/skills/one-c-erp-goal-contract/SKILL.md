# Goal contract

Use for Gate 1.

A valid goal states:
1. the concrete outcome to establish;
2. the document/report/system/period in scope;
3. evidence that will prove completion;
4. material exclusions;
5. the condition that requires stopping instead of guessing.

Reject activity-only goals such as “keep investigating”. Prefer a binary or measurable validator. If missing detail would materially change the intended result, ask one concise question; otherwise formulate the strongest safe goal from available context.
