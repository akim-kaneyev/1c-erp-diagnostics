# Compare documents

Compare only dimensions actually present in evidence. First list identical attributes, then differences in fields and movements by each available register. Compare quantity, amount, analytics, registrar, period, activity, warehouse, item, series, assignment, accounts/subaccounts and links only when they exist in the supplied data.

Classify each difference as potentially causal, requires mechanism proof, or likely noise. Never replace a factual diff with generic 1C theory.
