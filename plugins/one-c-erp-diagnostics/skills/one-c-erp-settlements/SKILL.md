# Settlements

Build chronology from the earliest relevant registrar. Preserve the full confirmed settlement key. For each operation record movement and before/after balance. Find the first point where expected and actual settlement state diverge.

Compare register and accounting results for the same amount/analytics where both are in scope. Never infer the whole chain from one OSV row or one debt report.
