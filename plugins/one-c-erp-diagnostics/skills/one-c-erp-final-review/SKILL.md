# Final review

Check Gate 1–10 statuses. Required gates must be `passed` or `not_required`. Any `pending`, `blocked`, `failed` or `stale` gate prevents clean closure.

Final output:
1. `Краткий вывод` — final status and proven cause or uncertainty;
2. `Основание` — decisive evidence and causal chain;
3. `Что делать дальше` — safe action or smallest missing evidence;
4. compact Gate 1–10 status table/list;
5. remaining blind spots and falsifiers.
