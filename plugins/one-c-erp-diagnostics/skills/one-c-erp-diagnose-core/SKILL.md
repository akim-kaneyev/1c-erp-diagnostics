# Core diagnosis

Use for Gate 4.

1. Separate established facts, interpretations, hypotheses and missing evidence.
2. Build chronology from the earliest relevant registrar.
3. Compare control/problem or before/after on identical dimensions.
4. Identify the earliest proven divergence rather than the last visible symptom.
5. Build the chain `document → movement → record/register → consuming mechanism → result → symptom`.
6. For every hypothesis record support, contradiction, confirm condition and falsify condition.
7. Do not name a root cause until the mechanism consuming the divergent record is shown or otherwise proven.
8. If the declared goal is an exact cause but the only evidence is a symptom statement, Gate 4 is `blocked`, not `not_required`; later synthesis/review may still pass by correctly rejecting an unsupported cause.

## Mandatory accounting invariant module

For expense allocation, cost, month close, balances, postings and any proportional algorithm, execute [the accounting invariants interface](references/accounting-invariants.md) on sanitized primary rows before root-cause establishment or correction design.

The result becomes derived Evidence with its input hash and execution identity. A manual total, spreadsheet summary or author-produced derived total cannot replace it. Build/load/activate remains prohibited until both baseline/proposed arithmetic and independent semantic Gate 7 pass.
