# Core diagnosis

Use for Gate 4.

1. Separate established facts, interpretations, hypotheses and missing evidence.
2. Build chronology from the earliest relevant registrar.
3. Compare control/problem or before/after on identical dimensions.
4. Identify the earliest proven divergence rather than the last visible symptom.
5. Build the chain `document → movement → record/register → consuming mechanism → result → symptom`.
6. For every hypothesis record support, contradiction, confirm condition and falsify condition.
7. Do not name a root cause until the mechanism consuming the divergent record is shown or otherwise proven.
