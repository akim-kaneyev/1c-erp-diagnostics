# MXL policy

В репозитории нет выдуманного универсального MXL-парсера.

Без подтвержденного формата конкретного `.mxl` безопасный порядок:
1. Сохранить исходный MXL неизменным вне Git.
2. В 1С экспортировать тот же табличный документ в XLSX, PDF, HTML, XML или TXT/CSV, если структура не теряется.
3. Для структурного анализа приоритет XLSX/XML.
4. Для визуальной проверки — PDF.
5. Зафиксировать связь экспорта с исходным MXL.

Конкретный MXL-конвертер добавляется только после проверки и с тестами.
