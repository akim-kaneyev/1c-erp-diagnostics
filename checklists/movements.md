# Чек-лист: движения документа

Проверять по фактической выгрузке:
- документ и дата;
- проведен / не проведен;
- регистратор;
- список регистров;
- период записи;
- вид движения;
- количество;
- сумма;
- организация;
- склад;
- номенклатура;
- серия;
- назначение/аналитика, если присутствует;
- активность;
- сторно/отмена, если присутствует;
- различия относительно контрольного документа.

Нельзя считать пустое поле ошибкой без знания механизма и нельзя переносить набор движений одного вида документа на другой без доказательства.
