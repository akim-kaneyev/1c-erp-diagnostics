# Чек-лист: регистры

Для каждого фактически найденного регистра:
1. Полное имя из выгрузки/метаданных.
2. Тип регистра, если подтвержден.
3. Измерения и ресурсы.
4. Регистратор.
5. Период и активность.
6. Ключевые аналитики.
7. Остаток до операции.
8. Движение операции.
9. Остаток после.
10. Сопоставление с контрольным примером.

Для причинного вывода показать, какой последующий механизм использует эту запись.
