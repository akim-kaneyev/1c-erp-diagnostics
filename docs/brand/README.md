# Brand guide — approved Velis mascot identity

## Approved composition

The production identity is the approved emblem with:

- one white dog mascot;
- one Velis medallion on the collar;
- one diagnostic magnifying glass;
- a moonlit mountain and waterfall background;
- the `1C ERP Diagnostics · Ecosystem` nameplate.

The separate duplicate medallion from an earlier draft is not part of the approved logo.

## Trademark boundary

The visual artwork is original and does not include the corporate 1C logo. References to 1C:ERP are descriptive. The repository must retain its independent-project disclaimer and trademark notice.
