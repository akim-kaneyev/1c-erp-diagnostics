# Velis / 1C ERP Diagnostics 0.5.0

The new local UI SDK workbench connects to an explicitly selected test contour, collects authenticated read evidence and keeps private cases, separate notes and verified source packages. It also provides three reproducible row checks: comparison, negative balances and exact-decimal expense allocation. Examples are explicitly synthetic, and check results do not establish an accounting cause.

The immutable file viewer and strict `EVAL_RESULT_JSON` diagnostics remain available. Profiles contain no passwords; sessions expire after 15 minutes. The first-party VelisReadOnlyBridge source accepts only fixed commands; legacy bridge limitations remain visible. No installation or database publication occurs merely by starting the workbench.
